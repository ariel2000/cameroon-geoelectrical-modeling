# Оценка параметров типичных моделей камерунских месторождений геоэлектрическими методами, включая частный случай нефтегазовых зон

Воспроизводимое исследование возможностей DC/ERT и IP для **оценки параметров**
рудных синтетических моделей, а также глубинного каротажа сопротивления для
частного случая нефтегазового резервуара. Модели построены по опубликованным
полевым и скважинным работам в Камеруне.

**Автор:** Буну Гимкинг Ариэль, группа ФГ-51М, НГТУ
**Научный руководитель:** к.т.н. А. Ю. Соболев

## Цель исследования

Цель состоит не в простом доказательстве обнаружимости аномалии. Для каждой
модели необходимо:

1. задать известные истинные геометрические и электрические параметры;
2. рассчитать синтетические DC/IP данные и электрический каротаж;
3. добавить воспроизводимый шум;
4. оценить геометрию и электрические параметры каждой цели;
5. вычислить ошибки восстановления;
6. сопоставить оценки с параметрами, полученными в камерунских полевых работах.

Чувствительность, шум и сходимость сетки используются как средства проверки
качества оценки, а не как самостоятельная цель работы.

## Выбранные методы и модели

DC и IP выбраны для рудных целей, поскольку они реализованы в SimPEG и имеют
непосредственные полевые аналоги в Камеруне. Для глубокого нефтегазового
случая выбран каротаж сопротивления, поскольку опубликованные параметры Douala
и Rio del Rey получены в скважинах, а глубины до 5 км недоступны принятой
поверхностной установке.

| Сценарий | Полевой аналог | Оцениваемые параметры |
|---|---|---|
| Золото-сульфидная зона | Bindiba и Yassa | кровля, ширина, сопротивление, зарядоспособность |
| Канал железной минерализации | Messondo | кровля, ширина, сопротивление, зарядоспособность |
| Нефтегазовый песчаник (частный случай) | Rio del Rey и Douala | кровля, мощность, сопротивление, условная водонасыщенность |

Параметры коры выветривания ограничены результатами Robain et al. (1996) для
Nko'ongop. TDEM не включён в основное сравнение: доступная 1D-реализация не
представляет конечное 2D рудное тело и не имеет эквивалентного набора полевых
TDEM-параметров в используемых камерунских источниках.

## Основные результаты

Для двадцати реализаций шума и условной сеточной оценки получено:

| Модель | Параметр | Истина | Медианная оценка | Ошибка |
|---|---|---:|---:|---:|
| Золото-сульфидная | кровля, м | 15 | 20 | +33,3 % |
|  | ширина, м | 75 | 80 | +6,7 % |
|  | сопротивление, Ом·м | 550 | 600 | +9,1 % |
|  | зарядоспособность, В/В | 0,047 | 0,050 | +6,4 % |
| Железная | кровля, м | 10 | 15 | +50,0 % |
|  | ширина, м | 140 | 150 | +7,1 % |
|  | сопротивление, Ом·м | 1650 | 1500 | −9,1 % |
|  | зарядоспособность, В/В | 0,020 | 0,018 | −10,0 % |
| Нефтегазовая | кровля, м | 4898 | 4900 | +2 м |
|  | мощность, м | 34 | 32 | −5,9 % |
|  | сопротивление, Ом·м | 3,4 | 3,5 | +2,9 % |
|  | водонасыщенность | 0,349 | 0,343 | −1,8 % |

Электрические свойства и ширина восстанавливаются лучше глубины. Все итоговые
оценки остаются согласованными с опубликованными интервалами Bindiba,
Messondo и Rio del Rey. Это показывает потенциал выбранных методов для оценки
параметров, но не устраняет ограничение вертикального разрешения. Каротаж
сопротивления сам по себе не различает нефть и газ.

## Численная проверка

DC/IP решаются на 2D адаптивной TreeMesh методом конечных объёмов. Сравнение с
сеткой 2,5 м показывает, что сетка 5 м отличается примерно на 2,14 % для DC и
9,26 % для IP. Поэтому итоговые оценки выполнены на сетке 2,5 м.

## Воспроизведение

```bash
conda env create -f environment.yml
conda activate cameroon-geoelectrical
python scripts/run_all.py
python -m pytest -q
```

Или с `venv`:

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements-dev.txt
python scripts/run_all.py
```

Полный расчёт с сеткой 2,5 м может занимать более десяти минут. Все исходные
параметры находятся в `scripts/model_parameters.json` и
`scripts/model_scenarios.json`; нефтегазовый сценарий — в
`scripts/petroleum_scenario.json`, а полевые интервалы — в
`data/field_benchmarks.csv`.

## Ограничения

- используются синтетические, а не исходные полевые данные;
- оценка условная: группы параметров варьируются при фиксированных остальных;
- синтетические данные и подбор используют один прямой оператор;
- 2D модель предполагает бесконечное простирание поперёк профиля;
- сравнение с публикациями проверяет согласованность интервалов, но не является
  независимой инверсией полевых данных.
- нефтегазовая водонасыщенность условна относительно принятых параметров
  Simandoux; различение нефти и газа требует дополнительных каротажных данных.

Эти ограничения не меняют цель исследования, а определяют уровень доказательности
полученных оценок.
