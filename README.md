# Геоэлектрическое моделирование тропического профиля выветривания Камеруна

Воспроизводимое исследование синтетических откликов постоянного тока (DC),
вызванной поляризации (IP) и переходного электромагнитного метода (TDEM) для
упрощённого профиля «латерит — сапролит — фундамент» с проводящей и
поляризующейся целью.

**Автор:** Буну Гимкинг Ариэль, группа ФГ-51М, НГТУ
**Научный руководитель:** к.т.н. А. Ю. Соболев

## Исследовательский вопрос

При каких глубине, размере и электрическом контрасте минерализованное тело
может быть обнаружено и его параметры оценены методами DC, IP и TDEM под
проводящим тропическим реголитом?

В репозитории слово «возможности» определяется количественно через:

- изменение синтетического сигнала при изменении параметра;
- отношение RMS-амплитуды аномалии к принятой модели ошибок;
- устойчивость результата к пространственной дискретизации;
- восстановление параметров из зашумлённых синтетических данных;
- неоднозначность и ограничения выбранной размерности.

## Область применимости

| Метод | Реализация | Интерпретируемая модель |
|---|---|---|
| DC | SimPEG `Simulation2DNodal` | 2D тело бесконечного простирания |
| IP | SimPEG `Simulation2DNodal` | та же 2D геометрия, зарядоспособность в В/В |
| TDEM | SimPEG `Simulation1DLayered` | горизонтально бесконечный эквивалентный проводящий слой |

TDEM 1D **не представляет тело конечной ширины 80 м**. Поэтому его амплитуда
и обнаруживаемость не сравниваются напрямую с 2D DC/IP. TDEM-эксперимент
оценивает влияние вертикальной слоистости и эквивалентного проводящего слоя.
Переход к конечному телу требует 3D TDEM и рассматривается как отдельное
расширение, а не как скрытое допущение.

## Эталонный сценарий

Поверхность имеет координату `z = 0 м`; глубина отрицательна в 2D модели.

| Элемент | Толщина / положение | Удельное сопротивление | Зарядоспособность |
|---|---:|---:|---:|
| Латерит | 15 м | 80 Ом·м | 0 в базовом сценарии |
| Сапролит | 30 м | 200 Ом·м | 0 в базовом сценарии |
| Фундамент | полупространство | 1000 Ом·м | 0 |
| Цель | кровля 100 м; 80 × 40 м | 10 Ом·м | 0,15 В/В |

Значения задают **контролируемый эталонный сценарий**, а не доказанную
универсальную модель всех камерунских месторождений. Мотивация и ограничения
приведены в [`docs/SCIENTIFIC_SCOPE.md`](docs/SCIENTIFIC_SCOPE.md).

## Основные проверенные результаты

- Различие откликов сеток 5 и 2,5 м составляет около **0,44 % для DC** и
  **0,56 % для IP**.
- Для цели с кровлей 100 м RMS-отношение аномалия/шум составляет около
  **0,47 для DC** и **0,08 для IP**. Обнаруживаемость этой цели выбранной
  установкой не доказана.
- Совместный DC/IP поиск имеет плоскую область близких решений и показывает
  неоднозначность глубины и ширины.
- В TDEM 1D истинные параметры `[95 м, 35 м, 12 Ом·м]` восстановлены примерно
  как `[93,3 м, 39,0 м, 13,3 Ом·м]`, NRMS ≈ 1,13. Результат относится только к
  горизонтально бесконечному слою.

Численные таблицы находятся в [`outputs/`](outputs/), интерпретация — в
[`docs/RESULTS.md`](docs/RESULTS.md).

## Установка

### Conda (рекомендуется для Windows/Anaconda)

```bash
conda env create -f environment.yml
conda activate cameroon-geoelectrical
```

### venv / pip

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements-dev.txt
```

В Linux/macOS: `source .venv/bin/activate`.

## Численный метод

В 2D DC/IP используется адаптивная квадродеревная сетка и совместимая
**конечно-объёмная** дискретизация SimPEG/discretize. Прежнее утверждение о
методе конечных элементов исправлено. TDEM решается модулем слоистой 1D среды.

## Ограничения

- полевых данных для независимой проверки нет;
- петрофизические параметры имеют широкие природные диапазоны;
- топография, анизотропия, сезонное насыщение и геологические помехи не включены;
- DC/IP восстановление является параметрическим поиском, а не свободной
  томографической инверсией;
- синтетические данные и восстановление используют один прямой оператор,
  поэтому неопределённость восстановления остаётся оптимистичной;
- TDEM 1D завышает объём проводника относительно конечного 2D/3D тела;
- выводы относятся только к протестированным сценариям.
