# Параметры эталонного сценария

| Элемент | Сопротивление, Ом·м | Проводимость, См/м | Зарядоспособность, В/В |
|---|---:|---:|---:|
| Латерит | 80 | 0,0125 | 0 |
| Сапролит | 200 | 0,005 | 0 |
| Фундамент | 1000 | 0,001 | 0 |
| Цель | 10 | 0,1 | 0,15 |

Машиночитаемым первичным источником является
`scripts/model_parameters.json`. Проводимость вычисляется в коде как обратная
величина сопротивления; дублированные JSON значения проверяются автоматически.
